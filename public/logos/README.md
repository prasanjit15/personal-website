## How to Add Logos:
1. Download or create PNG versions of each logo
2. Name them exactly as listed above (lowercase, underscores for spaces)
3. Recommended size: 64x64px or 128x128px
4. Ensure transparent backgrounds for best results

## Fallback:
If any logo file is missing, the component will automatically fall back to displaying the technology name as text.
